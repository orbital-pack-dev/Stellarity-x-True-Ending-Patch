# 🌌 Stellarity x True Ending Cosmetic Patch

![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)
![Minecraft Version](https://img.shields.io/badge/Minecraft-1.21-brightgreen.svg)

> **Compatibility Patch** (Легальный патч-слой для Modrinth). Заглушка логики Stellarity + склейка глубоко проработанных атак True Ending с невероятным визуалом от Stellarity.

---

## 📖 Обзор

Этот патч-слой предназначен для бесшовной интеграции двух потрясающих дата-паков для Энда: **Stellarity** и **True Ending**. 
Вместо того чтобы они конфликтовали между собой, мы отключаем конфликтные механики и объединяем лучшие черты обоих модов: 
интеллектуальный ИИ дракона и атаки из True Ending с завораживающими визуальными эффектами, партиклами и небом из Stellarity.

## ✨ Ключевые Фичи

* 🐉 **Гибридный Босс-файт**
  * Использует продвинутый ИИ Дракона из *True Ending*.
  * Вплетает эффекты, свечение и частицы заклинаний из *Stellarity*.
* 🔮 **Фантомы-Стражи**
  * Улучшенные башни с кристаллами защищены рандомизированными Фантомами.
  * Красивые орбиты, уникальные размеры и высота полёта фантомов для каждой башни.
* 🛡️ **Неуязвимость и Интерактивные Щиты**
  * Кристаллы надежно защищены от прямого урона до призыва дракона.
  * При полных кристаллах Дракон корректно уходит в защиту и не получает урон (визуализировано новыми красивыми щитами у портала).
* ☄️ **Кастомное Яйцо Дракона**
  * Потрясающая анимация свечения Яйца с выверенной центровкой частиц!
* 🎨 **Облегчённый Ресурс-Пак (Visual Effects+)**
  * Содержит **только** необходимое для Энда: кастомное небо, туман, босс-бар и новые частицы дыхания и взрывов.
  * Никакого лишнего мусора из обычного мира или Незера.

## 📥 Установка

1. Установите оригинальные дата-паки **True Ending** и **Stellarity**.
2. Поместите поверх них **Stellarity Cosmetic Patch** (этот дата-пак).
3. Активируйте прилагаемый ресурс-пак **Visual Effects+** для полного погружения (кастомные иконки в меню, небо и частицы).
