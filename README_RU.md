# Stellarity x True Ending: Compatibility & Mechanics Patch

[Вставить Картинку: Главный Баннер проекта]

**Stellarity x True Ending Patch** — это неофициальный дата-пак, созданный для идеального слияния двух самых глобальных модов на Эндер Дракона: **Stellarity** и **True Ending**.

Вам больше не нужно выбирать между эпичными фазами True Ending и красивыми визуалами Stellarity. Этот патч бережно объединяет механики обоих проектов, исправляя баги ваниллы, Paper и конфликты между самими модами.

---

## 📦 Две версии на выбор

Мы понимаем, что каждый сервер уникален. Поэтому патч разделен на две версии: выберите ту, которая подходит именно вам!

[Вставить Картинку: Сравнение версий или скриншот битвы]

### 🟢 1. Compatibility Patch (Обычная Версия)

Идеально для тех, кто хочет получить **чистый опыт оригинальных модов** без отсебятины. Включает только фиксы и базовую совместимость.

* **Исправление хитбоксов**: Исправлен баг True Ending с фантомным хитбоксом невидимого Дракона (теперь по нему нельзя случайно попасть во время перелетов).
* **Фикс генерации кристаллов**: Высота кристаллов Stellarity адаптирована под измененные башни из True Ending.
* **Механика неуязвимости Stellarity**: Дракон не получает урон, пока живы кристаллы Края (грамотно вплетено в фазы True Ending).
* **Исправление лучей**: Луч от кристаллов больше не бьет в нулевые координаты (0, 0, 0), ломая визуал.
* **Светящееся Яйцо Дракона**: Визуальный фикс яйца.
* **Фантомы-стражи**: Механика фантомов, защищающих башни из Stellarity, полностью работает.

### 🔴 2. Mechanics Patch (Модифицированная Версия)

Для настоящих хардкорщиков. Включает в себя всё из Обычной Версии, **плюс новые уникальные механики**, бросающие вызов даже самым одетым игрокам.

* **Блокировка Элитр**: Использование Элитр во время битвы с боссом невозможно. Летать над Эндом больше не выйдет!
* **Опасный Портал**: Портал в обычный мир изрыгает Драконье Дыхание (опасную зону), если Дракон находится далеко, чтобы вы не отсиживались в центре.
* **Дебафф на урон**: Игроки получают эффект *Слабости I* (Weakness I) во время битвы.
* **Вторая Жизнь (Фаза Тотема)**: Секретная фаза! При получении смертельного урона Дракон использует Тотем Бессмертия, восстанавливая часть здоровья и продолжая бой.
* **Вихрь бездны**: Уникальный визуальный и физический эффект затягивающего вихря вокруг Дракона.

## 📥 Установка и Порядок Загрузки (Load Order)

[Вставить Картинку: Инструкция / Иконка папки]

Патч поставляется в двух удобных форматах: **как дата-пак (.zip)** и **как глобальный мод (.jar)**.

### 1. Необходимые зависимости (Установите их первыми)

* **True Ending** (Версия 1.1.4d) — *Дата-пак/Мод и Ресурс-пак*
* **Stellarity** (Версия 5.5.5) — *Дата-пак/Мод и Ресурс-пак*

### 2. Установка (Выбери свой вариант)

**Вариант А: Если вы используете ядра (Fabric / Quilt / Forge / NeoForge / Paper / Purpur)**
Просто скачайте наш патч в формате **.jar** и закиньте его в папку `mods/` вашего сервера (или клиента, если играете в одиночку).
*Загрузчики модов сами распознают его и загрузят как глобальный дата-пак!*

**Вариант Б: Классический Дата-пак (Vanilla)**
Скачайте патч в формате **.zip** и поместите его в папку `datapacks` вашего мира.

⚠️ **ВАЖНО! Порядок загрузки в `datapacks` (от низшего к высшему приоритету):**

1. `tru.e-ending`
2. `Stellarity`
3. `Stellarity_Compatibility_Patch` **ИЛИ** `Stellarity_Mechanics_Patch` (Самый высокий приоритет)

### 3. Ресурс-паки (Обязательно!)

Не забудьте установить ресурс-паки для корректного отображения моделей и текстур.
Порядок загрузки в игре (`resourcepacks`):

1. `True Ending RP`
2. `Stellarity RP`
3. `Stellarity_Cosmetic_RP` (Опционально, если используете)
