# Stellarity x True Ending — Косметический Патч (ste_cos)

Аддон-слой поверх работающей связки **Stellarity 5.5.4** + **True Ending 1.1.4d**.
НЕ переписывает бой. Добавляет точечные исправления и зрелищность.

## Порядок дата-паков (сверху вниз)
1. `Stellarity-5.5.4`
2. `tru.e-ending-1.1.4d`
3. `Stellarity_Cosmetic_Patch`  ← сверху

## Настройка здоровью
True Ending настраивает здоровье дракона через свой дата-пак (settings).
Косметический патч здоровья НЕ трогает.

## Что делает

### 1) Неуязвимость дракона, пока живы кристаллы
`data/ste_cos/function/dragon/invulnerability_guard.mcfunction`
Каждый тик: пока есть живые кристаллы `ShowBottom:1b` —
дракону `Invulnerable:1b` + `resistance 255`. Как только кристаллы
уничтожены — `Invulnerable:0b`. Предотвращает убийство в 1-й фазе.
Здоровье и фазы TE не затрагиваются.

### 2) Фантомы-стражи у кристаллов
`data/ste_cos/function/phantom/*`
- Для каждого живого кристалла создаётся маркер привязки + фантом (`ste_cos_guard`).
- Фантом с `NoAI:1b` кружит по орбите радиуса 4 вокруг кристалла.
- Если игрок (не spectator/creative) в радиусе 20 блоков — фантому включается
  `NoAI:0b`, и он сам атакует игрока.
- Когда кристалл умирает — маркер и фантом убиваются.

### 3) Фикс Тройного-Нырка (копии дракона)
`data/true_ending/function/boss/dive/decoy_enderdragon_summon.mcfunction`
Заменяет невалидный `spreadplayers ~ ~` + спавн на `~ ~128 ~`.
Копии спавнятся относительно дракона: правая (`bosstime 1020`) и левая
(`bosstime 1050`), чуть выше и вперёд. Теги сохранены.

### 4) Присмертная посадка на 12 блоков выше
`data/true_ending/function/boss/phase_totem.mcfunction`
Посадка на центральный портал поднята с `~ ~2 ~` на `~ ~14 ~`
(на ~12 блоков выше) в присмертной фазе.

## Очистка
- Маркеры/фантомы стражей падают сами при смерти кристалла.
- Отключается целиком убиранием пакета из списка дата-паков.
